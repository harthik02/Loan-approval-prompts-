PHASE 6 REQUIREMENTS
==================================================

1. API LAYER

Create or complete the appropriate API layer using the framework already intended by the project architecture.

The API should provide a clean entry point for submitting a loan application and obtaining the resulting decision.

At minimum support:

POST /api/loan/apply
- Accept applicant/loan application data
- Validate the request
- Invoke the existing LangGraph loan approval workflow
- Return the final decision and relevant analysis
- Handle workflow failures safely

GET /api/loan/{application_id}
- Retrieve the relevant application/decision information
- Return an appropriate response when the application does not exist

GET /api/health
- Return application health/status

Use proper:
- request validation
- response models
- HTTP status codes
- exception handling
- logging
- configuration management

Do not expose secrets or internal implementation details.

2. USER INTERFACE
==================================================

Create the user-facing interface using the Streamlit infrastructure already present/intended in the project.

The UI should allow a user to:

1. Enter applicant information.
2. Enter loan information.
3. Submit the application.
4. Trigger the existing loan approval workflow.
5. Display processing status.
6. Display the final decision.

The result should clearly display:

- Loan decision:
  APPROVED / REJECTED / MANUAL REVIEW
- Overall risk information
- Applicant/profile analysis
- Financial risk analysis
- Compliance result
- Important decision factors
- Any relevant warnings/errors

Make the UI clean, understandable and suitable for an academic demonstration project.

Do NOT put business/approval logic directly into Streamlit.
